# Changelog

## 1.0.0

First release.

- A panel, `/plancia`, for skills, plugins, MCP servers, subagents, rule files and hooks.
- Apply for this chat, Make default for the project; a summary to confirm before anything is written.
- Presets: Default, Minimal and your own, each saved as its differences from a parent.
- Protected items, proposed on first run and by `/plancia setup`: switching one off takes an extra confirmation.
- `/plancia reset` for the project, `/plancia reset --all` for every project.
- One line above the prompt with the preset in use and how many items are off.
- Claude's Write and Edit tools cannot change Plancia's own files.
